# Hot Ice

Hot Ice is a mobile-first daily sports player guessing game.

## Public Beta v55 Home Sport Options + ALL Mode

Updates:
- Home screen now shows NFL, MLB, NBA, and ALL option buttons instead of one big Play button
- Tapping a home sport button starts that sport’s daily challenge
- Added ALL mode as a true mixed-sport pool
- Sport clue/check only appears in ALL mode
- NFL/MLB/NBA-specific games hide the Sport clue and Sport match check because the sport is already known
- Search, answer pool, rankings, save state, and community stats respect the selected mode
- Keeps the Hot Ice color palette, sport-app layout, MLB API active rosters, no soccer, no PGA, share fix, streaks, and analytics
